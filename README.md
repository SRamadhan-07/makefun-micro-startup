A Python program that writes a one-sentence pitch for a startup renting pre-written apologies to agents who broke production.

Bounty: https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571

## Run

```sh
python3 main.py
```

This writes the entry text (UTF-8, single line) to `/output/entry.txt`.
